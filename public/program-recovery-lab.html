These are the real-life states we need to support. The admin defines program days, not weekdays. The user sees Day 1 through Day 7, with workout days and rest days included in one clear weekly rhythm.

Behavior rules

  • Admin setup: set sessions per week, then lay out Day 1 through Day 7.
  • User view: show the full week: workout days plus muted rest days.
  • Available day: recommend the next workout day in program order, skipping rest days.
  • Resume only drafts: only a workout the user already started can be resumed later.
  • Rest days: rest days are part of the program and are shown as low-pressure recovery days.
  • Busy week: if the week ends with unstarted workout days, do not carry debt forward. Start the next week clean.
